FUvarszervező V37 – GitHub Pages csomag
======================================

Feltöltés:
1. A ZIP teljes tartalmát másold a GitHub Pages tároló gyökérkönyvtárába.
2. A korábbi fájlokat cseréld le.
3. Feltöltés után használj Ctrl+F5 frissítést, telefonon zárd be és nyisd meg újra az oldalt.

V37 fő újdonságok:
- A sofőrönkénti „Nézet” ablak térképe görgetés közben is látható marad.
- Azonos felrakóhoz tartozó, különböző lerakójú buborékok a Nézetben alapból egy felrakási blokkot alkotnak.
- A blokk bármelyik húzófogantyújával az összes azonos felrakó együtt mozgatható.
- „Csoport bontása” gombbal a rendelések külön mozgathatóvá válnak.
- A 🔗 gombbal a bontott rendelések újra egy felrakási blokkba rendezhetők.
- A teljes autós felrakó–lerakó pár bontott állapotban is megszakíthatatlan egység marad.
- Megmaradt a V36 összes funkciója, a sofőrönkénti iránylogika, a Ryng javított címe és a hátralékkezelés.

Teszt:
- TEST_V37.js: 12/12 sikeres.
- V33, V34 és V35 kompatibilitási tesztek: 27/27 sikeres.
